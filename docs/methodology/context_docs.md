# Methodology — Context Docs (context/)

Every architectural context lives in `context/`. Each doc has YAML frontmatter declaring
`modules:` (the source files it owns) and `tests:` (the tests covering those modules).

Every tracked source file under `backend/`, `frontend/src/`, `ml-model/` must be owned by
**exactly one** context doc. The manifest (`context/_doc_manifest.json`) is the authoritative
file→doc map. It is generated by `scripts/build_doc_manifest.sh` and must never be hand-edited.

Exempt from ownership: `backend/tests/`, `frontend/src/**/__tests__/`, `ml-model/tests/`,
`docs/`, `.github/`, `ml-model/data/`, files starting with `_`, files matching
`test_*`, `demo_*`, `*_probe.*`, `package-init`.
